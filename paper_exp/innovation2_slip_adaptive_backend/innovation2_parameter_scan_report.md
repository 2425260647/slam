## 建议

注意：`scan_r055_h0030` 虽然地图面积最小，但它没有触发任何 odometry 降权，`weight_scale_min=1.0`、日志触发 0，因此不能作为“创新点二有效参数”使用。

有效候选中建议优先选择 `scan_r050_h0030`：`slip_lidar_reliability_min=0.50`，`slip_high_threshold=0.030`，`slip_low_threshold=0.012`。它相对 Slip B 静态高权重同时改善 map 面积、占据连通分量和 PCA 横向宽度 P90，并且后续 Reference 原始 bag 复验证明没有误触发。

`scan_r055_h0025` 作为备选：它的连通分量更低，但 PCA 横向宽度略变差，更适合强调碎裂抑制，不如 `scan_r050_h0030` 均衡。
