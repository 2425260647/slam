## 2. “3 条独立序列”的准确定义

只有一条长走廊满足条件时，允许在**同一条物理走廊分别录制 3 次**。

必须满足：

1. 每次都是一次新的真实机器人往返行驶。
2. 每次单独启动和停止 rosbag，得到 3 个不同文件。
3. 不能将同一 bag 重复播放 3 次当作 3 条独立序列。
4. 3 次使用相同起点、初始朝向、电梯厅路线、掉头区域和回程路线。
5. 3 次的参数设置在正式对比阶段必须保持不变。

建议文件名和数据划分：

| 文件 | 用途 | 是否允许调参 |
|---|---|---|
| `corridor_repeat_01.bag` | 验证集，确定阈值和权重 | 允许 |
| `corridor_repeat_02.bag` | 测试集 A | 不允许 |
| `corridor_repeat_03.bag` | 测试集 B/重复性验证 | 不允许 |
| `corridor_dynamic_01.bag` | 可选的行人/障碍物压力测试 | 不允许 |

论文中应表述为：

> 在同一长走廊场地独立采集 3 次完整往返序列，用于评价方法的重复性和参数冻结后的测试性能。

不得表述为“在 3 个不同长走廊环境中实验”。

## 3. 标准录包流程

1. 在地面标记固定起点、初始朝向、电梯厅路线和尽头掉头区。
2. 录包开始后原地静止 10 s。
3. 以约 `0.3～0.5 m/s` 速度按预定路线行驶。
4. 去程和回程在电梯厅采用相同路线。
5. 在固定区域掉头，沿原路返回。
6. 到达起点后静止 10 s，然后停止录包。
7. 优先记录原始 `/velodyne_points`、`/odom`、`/tf`、`/tf_static`。
8. 每次录制后立即检查时长、话题频率、点云点数、odom 连续性和 TF 发布者。

## 5. 一致性异常注入计划

1. 使用独立 ROS 节点订阅原始 `/odom`，发布 `/odom_injected`。
2. 不直接修改原始 bag，不把注入代码写入 Cartographer 核心。
3. 对相对位姿增量注入连续 3～5 s 的横向与 yaw 偏差，不制造单帧位姿瞬移。
4. 轻度级：累积横向 `0.2 m`，yaw `0.05 rad`。
5. 中度级：累积横向 `0.35 m`，yaw `0.10 rad`。
6. 建议在 3 个正式 bag 中共设置约 15～30 个独立异常事件。
7. 注入节点必须同步保存 `event_id,t_start,t_end,type,severity` 标签文件。
8. 评价事件级 Precision、Recall、F1、PR 曲线、检测延迟和恢复时间。
